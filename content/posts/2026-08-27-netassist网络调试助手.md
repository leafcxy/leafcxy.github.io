## 核心功能

### 1. 多协议 / 多模式支持

NetAssist 支持四种工作模式，覆盖绝大多数网络调试场景：

- **TCP Server**：监听指定端口，接受多个客户端连接；V5.15 新增防火墙功能，可通过黑/白名单管控客户端接入。
- **TCP Client**：主动连接远端服务器，支持断线自动重连。
- **UDP**：支持单播、组播（224.0.0.0–239.255.255.255）、多播、广播。
- **MQTT Client**：连接 MQTT Broker，支持发布/订阅，V5.0.10 版本引入。

同时全面支持 **IPv4 和 IPv6** 双协议栈（V5.0.9.0 起），适应现代网络环境。

---

### 2. 灵活的数据收发

- **ASCII / HEX 双模式**：发送和接收窗口均可在十六进制与 ASCII 码之间任意切换，支持中文显示。
- **编码支持**：ANSI 与 UTF-8 两种文字编码，中英混合场景无乱码。
- **转义字符解析**：发送框中输入 `\r\n` 等转义符，会自动解析为对应 ASCII 码发送。
- **AT 指令模式**：启用后在行尾自动补全 `\r\n`，方便调试 GSM/4G 模块。
- **校验位自动附加**：支持校验和、异或、CRC8、CRC16、CRC32 等多种格式，并可自定义 CRC 参数。

---

### 3. 高级发送功能

| 功能 | 说明 |
|------|------|
| 间隔 / 循环发送 | 设置发送间隔和循环次数，自动重复发送 |
| 批量发送 | 预定义多条指令并按顺序批量发出，可设置每条的发送延迟，支持从指定项开始 |
| 快捷指令 | 保存常用指令，支持自定义快捷键一键发送 |
| 文件导入发送 | 从外部文件导入数据作为发送内容 |
| 脚本动态发送 | 在发送内容中嵌入 C 语言脚本代码，实现动态数据生成与发送 |
| 历史记录 | 自动记录历史发送内容，随时调出重发 |

---

### 4. 自动应答

建立自动应答规则后，软件接收到匹配指令时会自动回复预设内容，支持：

- 正则字符集过滤（V5.0.9.0+）
- UTF-8 编码匹配（V5.0.13+）
- 应答延时参数设置
- CSV 格式的规则导入/导出（V5.0.14+）

这对于模拟服务端响应、压力测试场景非常有用。

---

### 5. 接收与日志

- **日志模式**：接收内容自动附加时间戳，方便分析通信时序。
- **数据自动保存**：接收数据可实时写入文件，支持「数据文件」和「滚动日志文件」两种方式（建议大数据量使用滚动日志，单文件上限约 4 GB）。
- **接收搜索**：右键菜单可对接收窗口内容进行关键字搜索。

---

### 6. 内置工具面板

NetAssist 不只是个收发工具，还集成了多个实用调试器：

- **部标 JT/T808 协议模拟器**：支持 JT/T808-2013 和 JT/T808-2019 协议，用于车联网平台联调。
- **Modbus 协议指令模拟器**：支持 RTU、ASCII、TCP 三种模式。
- **IEEE 754 浮点数转换器**：方便分析传感器、仪表等设备的浮点数据。
- **数据波形解析**：将接收到的字节流解析为图形波形，并可导出到 Excel 表格（V5.0.10+）。
- **GPS 调试工具**（V5.15 新增）、**整型转换**、**hex2bin / bin2hex 转换**等。
- **GSM 调试**（V5.0.14+）、**字符编码转换**（V5.0.14+）。

## 典型使用场景

1. **嵌入式设备联调**：将 MCU / DTU / 模组的网络端口与 NetAssist 对接，验证数据格式和通信逻辑。
2. **服务端程序测试**：用 TCP Client 模式连接自研服务器，快速验证协议解析是否正确。
3. **MQTT 物联网调试**：连接 MQTT Broker，发布/订阅主题，检查消息传递。
4. **UDP 广播测试**：局域网设备发现、组播测试。
5. **协议模拟**：利用自动应答 + 脚本代码模拟服务端，配合 CI 做集成测试。
6. **JT808 / Modbus 设备开发**：内置协议模拟器，无需额外工具即可完成协议级别的联调。

## 注意事项

1. **Windows Defender 误报**：软件本身安全无毒，但可能被 Windows 安全中心误报。首次使用前建议将其加入「病毒和威胁防护 → 排除项」白名单。
2. **中文乱码问题**：若在 UTF-8 代码页（活动代码页 65001）的系统上出现界面乱码，需进入「控制面板 → 区域和语言 → 管理 → 非 Unicode 程序的语言」，将系统区域改为「中文（简体，中国）」并取消 Beta 版 UTF-8 支持。
3. **scomm.dll 插件**：高级功能依赖 scomm.dll 插件，首次运行时软件会自动下载；若自动下载失败，请手动下载并放置在同目录。参考：[https://www.cmsoft.cn/resource/5.html](https://www.cmsoft.cn/resource/5.html)
4. **单文件大小上限**：接收数据存储为单文件时，上限约 4 GB（32 位文件系统限制），大数据量建议选择「滚动日志」模式。
