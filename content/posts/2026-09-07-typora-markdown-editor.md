写 Markdown 的人，多多少少都经历过这种割裂感：左边是满屏的 `#`、`**`、`> ` 符号，右边是渲染后的预览，两个窗口来回对照，写久了总有种"我到底是在写代码，还是在写文档"的错觉。分栏预览是绝大多数 Markdown 编辑器的标配，但真正把它做舒服、做到"无感"的，屈指可数。

[Typora](https://typora.io/) 就是其中之一——它用"所见即所得（WYSIWYG）"这一理念，彻底告别了源码与预览的分裂。

## Typora 是什么

Typora 是一款跨平台的 Markdown 编辑器，同时支持 **macOS、Windows 与 Linux**。它的核心设计只有一句话：**在哪里写，就在哪里看到最终效果**。

你输入 `# 标题`，光标一离开，那一行立刻变成真正的大号标题；输入 `**加粗**`，文字当场变粗；敲一个 `- ` 自动变成列表，回车继续。整个过程没有一个独立的"预览窗口"，文档本身就是最终渲染的样子。

这套机制让 Typora 更像一个专注的**写作工具**，而不是"代码编辑器 + 渲染器"的拼接。很多人上手 Typora 的第一感受就是：写文档终于顺畅了。

---

## 核心特性

Typora 功能克制但每一项都打磨到位，这里挑几个最常用的：

1. **所见即所得**：编辑与预览一体，无需分栏切换，专注写作本身。
2. **LaTeX 数学公式**：行内 `$...$` 与块级 `$$...$$` 实时渲染，配合 MathJax，写论文、记技术笔记非常顺手。
3. **代码块**：海量语言语法高亮，行号、复制按钮齐全，还能一键进入"专注源码模式"。
4. **表格、任务列表、脚注、目录（TOC）**：常用文档元素开箱即用，表格支持拖拽调整列宽。
5. **流程图 / 序列图**：内建 Mermaid 等图表语法，不用额外工具就能画图。
6. **文件管理 + 大纲**：左侧文件树与大纲联动，长文档快速定位。
7. **专注模式 / 打字机模式**：让光标始终停留在屏幕中央，屏蔽干扰。
8. **多主题 + 自定义 CSS**：内置多套主题，也能自己写 CSS 微调观感。
9. **导入导出**：可导出 PDF、HTML、Word、图片等，PDF 排版干净，适合交付。

## 为什么那么多人喜欢它

归结起来，Typora 的吸引力在于**把"写"这件事的摩擦力降到最低**：

- **零学习成本**：Markdown 语法本身简单，所见即所得又让人无需在脑内"预渲染"，新手几乎不用学就能上手。
- **对公式、图表、代码友好**：这是很多写技术博客、记学习笔记、写论文的人选它的直接原因。
- **导出质量高**：内置 PDF 导出排版工整，无需额外折腾 LaTeX 或浏览器打印。
- **跨平台、本地离线**：文档就是纯 `.md` 文件，不绑定云服务，数据完全掌握在自己手里。

当然，Typora 也并非万能。如果你需要的是**双向链接、图谱、插件生态**这类"第二大脑"式的知识管理，那 Obsidian 会更合适；如果你只是想在写代码的间隙顺手记两笔，VS Code 加个插件也够用。Typora 的定位始终是"专注的单篇写作"。
